## Что проверить перед сдачей

1. Добавить `product.html`, `order.html`, изображение, таблицу и переходы между всеми пятью страницами.
2. Завершить позиционирование, проверить БЭМ и описать собственные доработки.
3. Указать ФИО и группу в README.
4. Оформить Git-историю и PR по практическим, объединить результат в main и проверить GitHub Pages.
5. Открыть страницы на широком и узком экране; проверить все ссылки, фокус клавиатуры, открытие и закрытие диалога, ошибки и успешную проверку формы.
6. Подготовиться объяснить HTML, CSS, Flex/Grid, БЭМ и собственные решения. По методичке базовая реализация оценивается максимум в 2,5 из 5; дополнительные баллы требуют осмысленных самостоятельных доработок и защиты.

Выполнены локальная проверка структуры HTML, целей ссылок и якорей, проверка JavaScript и diff.

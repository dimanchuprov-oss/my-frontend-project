# Учебный интернет-магазин

Проект по дисциплине «Фронтенд и бэкенд разработка».
Контрольная работа №1: «HTML и CSS: разработка многостраничного сайта».

Реализованы главная страница, каталог со статическим блоком фильтров и контакты. Практические №5 и №6 выполнены в коде; подготовка всей контрольной ещё не закончена. Подробная проверка — в [CHECKLIST-KR1.md](CHECKLIST-KR1.md).

## Технологии и реализация

HTML5, CSS3, JavaScript без фреймворков и сторонних библиотек.

- Единая навигация, активный пункт через `aria-current`, уникальные `title` и `meta description`.
- Семантические `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Якоря на главной, ссылки на разделы с внутренних страниц, хлебные крошки.
- Плавная прокрутка и выделение цели через `:target`; учтено предпочтение уменьшенного движения.
- Flexbox для меню и внутренней структуры карточек, кнопки прижаты к низу.
- Grid для карточек и каталога: области `filters` и `products`.
- Статические фильтры с `fieldset`, `legend`, категориями и диапазоном цены. Кнопка применения отключена: реальная фильтрация не входит в №6 и КР №1.
- Общие CSS-переменные, состояния `:hover`, `:focus-visible`, `:disabled`.
- Модальное окно `<dialog>`: открытие по кнопке товара, закрытие крестиком, отменой, Escape или щелчком за границами окна.
- Поля имени, e-mail, телефона, даты, темы, комментария и согласия; HTML-валидация.
- Телефон вводится в формате `+7 (900) 000-00-00`.

Форма работает только на клиенте: сообщение подтверждает проверку, данные не отправляются и не сохраняются. Контакты вымышленные.

- Практическая 5: `catalog.html`, `contacts.html`, единое меню, якоря, хлебные крошки, метаданные.

Текущая ветка — `feature/css-architecture-states`; локальная `main` также ещё не содержит коммиты практических 3–4.

## Дополнительные улучшения

Активная страница выделена в меню; ссылки «Подробнее» ведут к конкретным карточкам главной; исправлен шаблон телефона; щелчок по внутренним отступам диалога больше не закрывает форму; сообщение формы прямо указывает на отсутствие отправки на сервер. Сохранена существующая поддержка узкого экрана и добавлено соответствующее расположение каталога.

Эти улучшения не заменяют недостающие обязательные элементы КР №1 и сами по себе не гарантируют повышенную оценку.

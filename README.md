# Учебный интернет-магазин

Практический frontend-проект по дисциплине «Фронтенд и бэкенд разработка». Сейчас реализована стартовая страница магазина с семантической HTML-разметкой, внешними стилями и интерактивной формой заявки.

## Реализовано

- Главная страница с блоками преимуществ и популярных товаров.
- Кнопки «Заказать» в карточках товаров.
- Модальное окно `<dialog>` с формой заявки.
- Поля имени, e-mail, телефона, даты, темы, комментария и согласия на обработку данных.
- Базовая HTML-валидация (`required`, `minlength`, `pattern`, `type`, `placeholder`).
- Открытие и закрытие модального окна через `js/main.js`.
- Клиентская проверка формы и сообщение «Форма успешно отправлена!».
- CSS-архитектура с блоком `:root` для цветов, отступов, скруглений и общих эффектов.
- Состояния `:hover`, `:focus-visible` и `:disabled` для ссылок, кнопок, карточек и элементов формы.
- Доработанные стили карточек товаров, формы заявки и модального окна.

## Структура

```text
index.html
css/style.css
js/main.js
```

## История выполнения

- Практические работы 1–2: создан Git-репозиторий и HTML/CSS-каркас стартовой страницы.
- Практическая работа 3: добавлены форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлена CSS-архитектура и состояния интерактивных элементов в ветке `feature/css-architecture-states`.

Для завершения GitHub-части работы нужно создать Pull Request из `feature/css-architecture-states` в `main` и после проверки объединить его с `main`.

Проект не подключается к backend: отправка формы демонстрирует клиентскую обработку и не сохраняет данные.

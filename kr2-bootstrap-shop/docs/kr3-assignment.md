# Контрольная работа №3

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Цель и основа проекта

Адаптировать многостраничный HTML/CSS-сайт под разные размеры экранов и проверить базовую доступность интерфейса.

КР №3 выполняется на основе проекта КР №1, а не Bootstrap-проекта КР №2. Это новая реализация в отдельном репозитории `kr3-responsive-shop/`.

## Что сдаётся

```text
kr3-responsive-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── contacts.html
├── css/
│   ├── style.css
│   └── responsive.css
├── images/
├── lighthouse/
│   └── report.png
├── README.md
└── .gitignore
```

В СДО сдаётся ссылка на итоговый репозиторий.

## Обязательные элементы

- Корректное отображение на мобильных, планшетных и desktop-экранах.
- Медиазапросы; желательно применять подход Mobile First.
- Перестраиваемые Flexbox/Grid-сетки и адаптивные карточки товаров.
- Изображения, не выходящие за пределы контейнеров.
- Адаптивные формы и таблицы характеристик.
- Доступность: видимый фокус, контраст, подписи полей и семантическая структура.
- Проверка Lighthouse; приложить отчёт или скриншот.
- README с описанием адаптивных решений, исправлений доступности, Lighthouse и ссылкой на публикацию (если используется GitHub Pages), а также ФИО и группой.

## Минимальные проверки адаптивности

Проверить минимум три диапазона:

| Устройство | Ширина |
| --- | --- |
| Мобильный экран | 360–430 px |
| Планшет | 768 px |
| Desktop | 1024–1440 px |

На этих ширинах проверить шапку и навигацию, каталог и карточки, страницу товара, форму заявки, таблицу, подвал и модальное окно (если используется).

## Минимальные проверки доступности

- Видимость фокуса при клавиатурной навигации.
- Наличие `label` у полей формы.
- Семантическая структура страниц.
- Достаточный контраст текста и фона.
- Осмысленные `alt` изображений.
- Корректная иерархия заголовков страниц и разделов.
- Отсутствие критических ошибок в Lighthouse.
